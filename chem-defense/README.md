# 元素防线 · Elemental Bastion

在浏览器里运行的**化学主题塔防游戏**：用元素与真实化合反应守护实验室，边玩边体会化学的美感与直觉。

## 快速开始

```bash
cd chem-defense
npm install
npm run dev
```

然后打开终端提示的本地地址（通常是 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

## 玩法

1. 选择关卡并在备战阶段布置防线；准备好后点击「开始第 N 波」主动开波。
2. 从元素货架选择 **H / O / C / N / Na / S / Cl / Fe** 并放置在网格上（避开管道路径）。
3. 将可反应的元素放在**相邻格子**，会自动合成更强的化合物塔：
   - `H + O → H₂O`
   - `Na + Cl → NaCl`
   - `H + Cl → HCl`
   - `C + O → CO₂`
   - `Fe + O → Fe₂O₃`
   - `S + O → SO₂`
4. 利用克制关系：
   - 碱（Na）克酸雾
   - 酸/卤素（Cl、HCl）克碱液
   - 氧克制甲烷火团（燃烧）
   - 硫/沉淀克制重金属离子
   - 氢/氮克制自由基
5. 选中塔后可升到 Lv.3；每级强化伤害、攻速和射程。出售会返还总投入的 60%。
6. 右侧「化学笔记」会解锁真实知识点与反应方程式。
7. 从第 3 波起，**AI 导演**会根据你的塔组成调整敌军配方，逼你用更完整的化学思路应对。

画布下方的控制条提供暂停与 **1× / 2× / 5× / 10×** 倍速；暂停时战场保持可见，点击画面即可继续。

快捷键：`1`–`8` 切换元素，`Space` 开波，`F` 循环倍速，`P` 暂停，`Esc` 取消选中。

## 关卡战役

| 关卡 | 波次 | 特点 |
| --- | ---: | --- |
| 基础实验室 | 8 | 宽松路线，学习元素合成与克制 |
| 腐蚀回廊 | 10 | 双折返路线，重金属与酸碱混合波 |
| 临界反应堆 | 12 | 短路线、高密度、双首领终局 |

通关按漏怪数获得 1–3 星并解锁下一关；关卡进度保存在浏览器 `localStorage`。

## 反馈与成就

- **连击**：短时间内连续击杀累积连击，最高提供 ×2 的能量与分数倍率，画面右上角有倒计时环
- **成就**：8 项成就（初次反应、全谱合成、链式反应、雪崩效应、零泄漏、衰变终结、化学学者、高产率），解锁时弹出提示并奖励能量
- **即时反馈**：程序合成音效、冲击环、屏幕震动、受击闪白、波次横幅、低血量警示
- **结算评级**：按漏怪数评定 S/A/B/C，并汇总击溃、最高连击、合成数与知识解锁量

## 技术

- Vite + TypeScript
- Canvas 2D 渲染，扁平化视觉以突出战斗信息
- Web Audio 程序化音效，无外部音频资源
- 轻量自适应波次 AI（根据元素/化合物标签调整敌人）
- 纯前端，无需后端；尊重 `prefers-reduced-motion`
